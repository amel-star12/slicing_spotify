Deskripsi Web:
Website ini adalah tiruan (clone) antarmuka Spotify sederhana yang menampilkan daftar lagu populer dalam bentuk card. 
Di sini, pengguna bisa berinteraksi langsung seperti memilih lagu, melihat informasi judul dan artis di bagian player, 
mengoperasikan menu navigasi saat dibuka lewat HP (tampilan mobile), serta mencoba tombol play dan pause yang interaktif.

Penerapan DOM:
Manipulasi DOM sudah diterapkan sepenuhnya. Data lagu tidak ditulis statis di HTML, melainkan di generate melalui JavaScript. 
Elemen card untuk setiap lagu dirakit menggunakan "document.createElement()" lalu disisipkan ke halaman dengan "appendChild()". 
Selain itu, event listener juga dipasang agar elemen seperti card lagu, tombol play/pause, menu mobile, 
serta tombol daftar dan masuk bisa merespons interaksi klik dengan baik.

Penerapan Ketentuan:
Semua ketentuan dasar proyek sudah terpenuhi, meliputi penggunaan HTML, CSS, JavaScript, manipulasi DOM, event listener, 
desain yang responsif, hingga penambahan aset gambar. Namun sebagai catatan, fitur seperti login, daftar, navigasi halaman, 
dan pemutaran audio masih sebatas simulasi antarmuka (UI) saja dan belum benar-benar terhubung ke sistem aslinya.
